# 중앙 봇 원본

번호 파일은 기능 단위 원본입니다. Apps Script에는 `node tools/build-apps-script.cjs`로 아래 7개 묶음을 각각 한 파일로 합쳐 올립니다.
합쳐도 동작은 같습니다. Apps Script는 모든 파일을 한 전역 공간에서 실행합니다.

| Apps Script 파일 | 내용 | 원본 |
| --- | --- | --- |
| `1_자동실행과발송` | 11시·17시 정기 실행, 개인 DM 만들기·보내기, 이어 보내기, 관리자 요약 | `09_자동실행.js`, `20_이어보내기.js`, `01_슬랙DM발송.js`, `23_운영알림.js` |
| `2_업무시트` | 업무 시트(HA-CV·PM Review·테스트지) 읽기와 업무 문안 | `05_업무시트연결.js`, `06_검수와어뷰저.js`, `13_담당탭읽기.js`, `07_업무브리핑.js`, `08_일별업무기록.js` |
| `3_슬랙` | BBPM 채널 미리 수집, 멘션 분류, Slack 영역 문안 | `12_슬랙키워드.js`, `03_슬랙수집.js`, `04_슬랙업무분류.js` |
| `4_캘린더연결` | PM 본인 캘린더 연결(초대·수신·회의 영역) | `02_캘린더일정.js`, `19_개인캘린더연결.js`, `21_캘린더연결초대.js`, `22_연결앱공유.js` |
| `5_점심과한마디` | 점심 추천과 오늘의 한마디 | `10_응원문구.js`, `15_점심추천.js` |
| `6_공통설정과점검` | 공통 설정·Slack 전송·운영 점검·명단 동기화 | `14_공통설정.js`, `17_운영점검.js`, `18_명단동기화.js` |
| `9_데이터` | 한마디 문구·식당 목록 기본 데이터 | `11_문구목록.js`, `16_식당목록.js` |

이름 끝에 `_`가 붙은 함수는 내부 함수, 없는 함수는 편집기에서 직접 실행하는 함수입니다. 목록: [docs/함수목록.md](../../docs/함수목록.md)
