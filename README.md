# 슬랙 봇 개인 업무 비서

PM마다 흩어져 있는 **업무 시트 · Slack 요청 · 캘린더 회의**를 모아, 평일 **10:30 · 14:00 · 17:00**에 각자의 Slack DM으로 알려 주는 봇입니다. 주말·공휴일·회사 휴무일은 쉽니다.
Google Apps Script와 Slack Web API만 사용합니다. 유료 AI나 외부 자동화 도구는 쓰지 않습니다.

## PM이 받는 DM (가상 예시)

```text
☀️ PM A 님, 10/26(월) 오전 브리핑 드립니다!
──────────
📌 오늘 확인할 업무
• 언어쌍 종료 임박 3건 — 남은 작업·종료 일정 확인
• 어뷰저 관리 2건 · 작성 기한: 10/26 (오늘) — 대상 확인·리스트 작성
   ↳ 관련 Slack [개인] 원문 10/26 · 기한 10/26(월) · 작성자B [이번 주 어뷰저 리스트 작성 요청]
──────────
📆 이번 주 종료 예정                       ← 월요일 오전만
• 10/30(금) en_US-ja_JP
──────────
📅 오늘 회의
• 15:00 리뷰 · 응답 전
• 15:30 주간 회의 · 응답 전
• ⚠️ 회의 겹침: 15:00 리뷰 ↔ 15:30 주간 회의
• 📨 응답 전 초대 2건 — 캘린더에서 참석 여부를 눌러주세요
──────────
💬 Slack
개인 · 새·변경
• NAC Scrum · 회의록 작성 · 원문 10/26
   ↳ 작성자C · [Scrum 일정 안내 및 회의록 작성 요청]
업무·회의 10:31 · Slack 10:25 기준          ← 회색 작은 글씨
──────────
🍚 점심 추천
• 예시식당 — 제육볶음으로 밥 한 공기 든든하게 먹을까요?
• 가볍게 · 예시카페 — 간단한 베이커리로 가볍게 챙겨볼까요?
🤝 오늘 예시식당 메이트: PM D 님 — 같이 가볼까요?
[ 점심 메이트 끄기 ]                        ← PM이 직접 누르는 버튼
──────────
✨ 오늘의 한마디
> 작은 한 칸도 진전으로 세어봐요.
이 브리핑 어땠나요?
[ 👍 도움됐어요 ] [ 👎 아쉬워요 ] [ ✍️ 자세히 남기기 ]   ← 피드백 버튼
```

- **14:00 DM**은 "오후 업데이트"입니다. 오전 DM 이후 새로 생긴 업무·Slack 요청만 보내고, 없으면 `오전 이후 새로운 알림이 없습니다. 점심 맛있게 드셨나요? 🍚` 한 줄만 보냅니다.
- **17:00 DM**은 "마무리 브리핑"입니다. 오늘 남은 회의와 내일 회의(10시 전 시작이면 `🌅 이른 시작`), 내일 날씨, 목·금요일 주말 인사가 붙고 점심 추천은 없습니다. 금요일에는 `📆 다음 주 초 미리보기`(월·화 기한 업무)가 붙습니다.
- 업무·프로젝트·Slack 항목 글씨에는 원문 링크가 걸립니다.
- **점심 메이트**는 PM이 버튼으로 직접 켜고 끕니다(기본 꺼짐). 켠 사람끼리만 이름이 보이고, 켠 사람들은 같은 식당이 겹치도록 날마다 3명당 1곳씩 나뉩니다.
- **피드백 버튼** 👍/👎은 봇 시트 BOT_FEEDBACK 탭에 쌓이고, ✍️는 구글 폼으로 연결됩니다.
- 명단에 문제가 있는 PM이 있어도 **그 PM만** 빠지거나(잘못된 Slack ID·중복) 업무 없이 받고(업무 시트 이름 불일치), 나머지는 정상으로 받습니다.
- 관리자에게는 회차마다 발송 결과·처리 시간·명단 문제·할 일을 요약한 DM이 한 통 더 갑니다.

## 어떻게 동작하나

```mermaid
flowchart LR
  A[업무 시트 사본] -->|회차 직전 읽기| C(중앙 봇)
  B[BBPM Slack 채널] -->|09:45~10:45, 13:30~14:15, 16:00~17:15 미리 수집| C
  D[PM 개인 캘린더] -->|PM 본인 승인 · 연결 앱이 5분마다 전달| C
  C -->|평일 10:30·14:00·17:00, 8명씩| E[PM별 Slack DM]
  C -->|회차 끝| F[관리자 요약 DM]
  E -->|점심 메이트·피드백 버튼| C
  G[날씨 API Open-Meteo] -->|17:00, 하루 1번| C
  H[대한민국의 휴일 캘린더] -->|공휴일이면 쉼| C
```

| 구성 | 하는 일 |
| --- | --- |
| **중앙 봇** (Apps Script 프로젝트 1) | 업무 시트를 읽고, Slack 수집본을 분류하고, 회의를 붙여 PM별 DM을 보냅니다. |
| **연결 앱** (Apps Script 프로젝트 2) | PM이 링크로 열어 **본인 Google 계정으로 승인**합니다. 본인 캘린더에서 본인이 참석하거나 만든 회의만 중앙 봇에 보냅니다. |
| **봇 전용 시트** | 업무 후보(BOT_TASKS), 수신자(BOT_USERS), 발송 기록, Slack 수집본을 저장합니다. 원본 업무 시트에는 쓰지 않습니다. |

## 빠른 시작 (개발)

```bash
node tools/test-local.cjs          # 합성 테스트 전체
node tools/build-apps-script.cjs   # Apps Script 업로드용 합본 7개 생성 → apps-script-deploy/
```

> **공개 데모본입니다.** 회사·채널·캘린더·식당 이름은 예시 값이고, 실제 운영 기록과 내부 문서는 넣지 않았습니다.
>
> 이 저장소는 공개용 사본입니다. 시트 ID·회사 도메인·Slack ID·사람 이름은 예시 값으로 바꿨고, 토큰·인증 파일·운영 기록은 넣지 않았습니다. 운영 프로젝트에 그대로 덮어쓰지 마세요.
