# 02. 운영 가이드

함수 위치는 **Apps Script 편집기의 합본 파일 → 함수** 순서로 적었습니다. 전체 목록은 [함수 목록](함수목록.md)을 보세요.
⚠️ 표시는 실제 DM 발송이나 설정 변경이 일어나는 함수입니다.

## 매일 할 일

평소에는 할 일이 없습니다. 회차가 끝나면 관리자에게 아래 같은 요약 DM이 옵니다.

```text
🛠 10:30 오전 정기 DM 점검 · 10/23(금)
• 발송 9/10명 완료
• 처리 시간 95초 · 묶음 2개 · 가장 긴 묶음 61초 (1명당 약 8초)
• 확인 필요: PM B
• 명단 확인 필요: PM E: 업무 시트 담당자 이름과 맞지 않음 → 업무 없이 발송
• Slack 자료 10:52 기준
• 일정 연결 9/10명 · 갱신 지연: PM C(10/23 09:00)
• 저장 공간 12KB / 500KB

👉 할 일
• Slack ID가 바뀌었거나 DM이 막힌 PM입니다. BOT_USERS의 Slack ID를 확인하세요.
```

`✅ 이상 없음`이면 끝입니다. "할 일"이 있으면 아래 표를 보세요.

## 할 일별 대응

| 요약에 나온 말 | 원인 | 할 일 |
| --- | --- | --- |
| Slack 봇 토큰 만료·해제 | `invalid_auth`, `token_revoked` | Slack 앱에서 새 봇 토큰(xoxb-)을 발급해 스크립트 속성 `SLACK_BOT_TOKEN`을 바꿉니다. 확인: `1_자동실행과발송` → `checkSlackBotToken` |
| Google 권한을 다시 승인 | 관리자 계정 권한 만료 | 편집기에서 아무 미리보기 함수나 한 번 실행해 승인 창을 통과합니다. |
| Slack ID가 바뀌었거나 DM이 막힘 | `channel_not_found`, `user_not_found` | 봇 시트 BOT_USERS의 Slack ID를 확인합니다. `6_공통설정과점검` → `previewRosterFromSlack`로 대조할 수 있습니다. |
| 전송 결과가 불분명 | Slack 응답 유실 | 자동으로 다시 보내지 않습니다. 해당 PM이 받았는지 직접 확인합니다. |
| Slack 자료 N분 지남 | 회차 전 수집 실패 | `3_슬랙` → `collectBbpmSnapshot` 실행 로그를 확인합니다. 요약에 최근 오류가 함께 나옵니다. |
| 일정 갱신 지연 | PM의 연결 앱 자동 갱신이 안 돎 | 해당 PM이 연결 화면에서 "지금 갱신"을 누르게 합니다. 계속되면 연결 앱 파일 공유(사내 전체 뷰어, 10/27 설정)를 확인합니다. |
| 명단 확인 필요 | BOT_USERS의 이름이 업무 시트 담당 탭 이름과 다름, Slack ID 형식 오류, 같은 이름·ID가 두 줄 | 그 PM만 빠지거나 업무 없이 받습니다(다른 PM은 정상). BOT_USERS A열 이름·B열 Slack ID·중복 줄을 고칩니다. |
| 연결 명단 제외 | 캘린더 연결 체크된 줄의 이메일·이름·Slack ID 중복이나 누락 | 그 줄만 빠집니다. BOT_USERS D열 이메일·E열 체크를 확인합니다. |
| 미연결 | 아직 캘린더를 연결하지 않음 | 아래 "PM 추가"의 초대를 보냅니다. |
| 묶음 4분 초과 | 인원 증가로 실행 시간 부족 위험 | 묶음 크기(8명)를 줄이는 코드 변경을 검토합니다. |
| ⚠️ 직전 회차 발송 기록 없음 | 앞 회차 트리거가 실행되지 않음(트리거 삭제·권한 만료·Google 장애) | 편집기 → 실행 기록에서 `sendScheduledBriefing` 실패를 봅니다. 트리거가 없으면 ⚠️ `1_자동실행과발송` → `installBriefingTriggers` |
| 연차 N명 건너뜀 | 해당 PM 캘린더에 종일 연차·휴가 일정 | 할 일 없음. 잘못 건너뛰었다면 그 PM 캘린더의 일정 제목을 확인합니다(끄기: 속성 `ENABLE_PERSONAL_LEAVE_SKIP`=false). |
| 이번 주 피드백 👍 n · 👎 n | 금요일 17:00에만 나옴 | 👎가 있으면 폼 응답(✍️)과 봇 시트 BOT_FEEDBACK을 함께 봅니다. |
| 저장 공간 정리 필요 | 스크립트 속성 400KB 이상 | `1_자동실행과발송` → ⚠️ `cleanupBotStorage` |

트리거 자체가 권한 만료로 시작하지 못하면 요약 DM도 오지 않습니다. 이때는 Google이 트리거 소유자에게 보내는 "실행 실패" 메일로 알 수 있습니다.

## PM 추가 (캘린더 연결 포함)

1. 봇 시트 BOT_USERS에 PM 행이 있는지 확인합니다. 없으면 `6_공통설정과점검` → ⚠️ `syncBotUsersFromSlack`(Slack 그룹에서 이름·Slack ID·이메일 채움, 발송 FALSE로 추가).
2. 그 행의 E열 `calendar_connect` 체크박스를 켭니다.
3. `4_캘린더연결` → `previewCalendarConnectionInvites`로 대상을 확인한 뒤 ⚠️ `sendCalendarConnectionInvites`로 초대 DM을 보냅니다.
4. PM이 링크에서 승인하면 발송이 자동으로 켜지고 확인 DM이 갑니다. 상태 확인: `4_캘린더연결` → `previewConnectedCalendarStatus`.

> 링크가 "현재 파일을 열 수 없습니다"로 막히면, 브라우저에 개인 Google 계정이 먼저 로그인된 경우입니다. 회사 계정만 로그인된 창(시크릿 창)에서 열면 됩니다. 초대 DM에도 이 안내가 들어 있습니다.

## 주요 스크립트 속성

| 속성 | 뜻 |
| --- | --- |
| `ENABLE_PM_SEND` | 실제 DM 발송 허용(전체 스위치) |
| `ENABLE_CONNECTED_PM_SEND` | 캘린더 연결을 마친 PM 전원에게 정기 발송(꺼지면 본인 시범 1명) |
| `ENABLE_SELF_CALENDAR_PIPELINE` / `ENABLE_CALENDAR_BRIEFING` | PM 본인 연결 캘린더 사용 / 회의 영역 표시 |
| `ENABLE_SLACK_MENTION_READ` / `ENABLE_SLACK_CHANNEL_DISCOVERY` | Slack 읽기 / BBPM 채널 자동 수집 |
| `SLACK_BOT_TOKEN`, `SLACK_PM_GROUP_ID`, `SLACK_DISCOVERY_CHANNEL_ID` | 봇 토큰, PM 그룹, 수집 채널 |
| `SLACK_SNAPSHOT_MAX_AGE_MINUTES` | 수집본 허용 시간(기본 60분) |
| `ENABLE_PERSONAL_LEAVE_SKIP` | 연차인 PM 건너뛰기(기본 켜짐, `false`면 끔) |
| `SOURCE_SPREADSHEET_ID`, `BOT_SPREADSHEET_ID` | 업무 시트 사본 / 봇 전용 시트 |
| `CALENDAR_CONNECT_URL`, `CONNECTOR_SIGNING_KEY` | 연결 앱 주소 / 연결 앱과 공유하는 서명 키 |
| `PILOT_PM_NAME` | 관리자(본인) 이름 — 시험 DM과 관리자 요약 수신자 |
| `ENABLE_LUNCH_RECOMMENDATION`, `ENABLE_BRIEFING_PHRASES` | `false`면 점심·한마디 제외 |
| `ENABLE_LUNCH_MATE`, `SLACK_VERIFICATION_TOKEN` | 점심 메이트 버튼 표시 / Slack 버튼 요청 검증 값 |
| `ENABLE_WEATHER`, `WEATHER_LAT`·`WEATHER_LON`·`WEATHER_PLACE` | 17:00 내일 날씨 / 위치(없으면 서울) |
| `ENABLE_FEEDBACK`, `FEEDBACK_FORM_URL` | `false`면 피드백 버튼 끄기 / ✍️ 버튼이 여는 구글 폼(없으면 기본 폼) |
| `COMPANY_HOLIDAYS` | 회사만 쉬는 날(`2026-12-31,2027-01-02`). 공휴일은 "대한민국의 휴일" 캘린더로 자동 판단 |

토큰과 키는 로그·채팅·코드·저장소에 남기지 않습니다.

## 설정 바꾸기 (스크립트 속성이 50개를 넘었을 때)

Apps Script는 스크립트 속성이 50개를 넘으면 "프로젝트 설정" 화면에서 편집할 수 없습니다. 이때는 봇 시트를 씁니다.

1. 봇 시트의 **`BOT_SETTINGS` 탭** B열(value)에 값을 적습니다. 따옴표 없이 값만 넣습니다. 탭이 없으면 아래 함수를 한 번 실행하면 생깁니다.
2. `6_공통설정과점검` → ⚠️ `applyBotSettings` 실행 → 로그에 `반영: …`이 나오면 성공입니다.
3. 반영한 값은 시트에서 자동으로 지워집니다(토큰이 남지 않음). 현재 값 확인: `previewBotSettings`.

정해 둔 이름(점심·날씨·한마디·피드백 스위치, 회사 휴무일, Slack 검증 값)만 받습니다. 실행할 때마다 C열 설명을 최신 문구로 맞추고, 새로 생긴 설정 이름은 아래에 빈 줄로 추가합니다. 값에 `삭제`를 적으면 그 설정을 지웁니다.

## 점심 메이트 켜기 (처음 한 번)

1. Apps Script 편집기 → 배포 → 배포 관리 → 중앙 봇 웹 앱 → 수정 → **새 버전** → 배포 (주소는 그대로)
2. Slack 앱 설정 → **Interactivity & Shortcuts** → On → Request URL에 중앙 봇 웹 앱 주소(`…/macros/s/<배포 ID>/exec`) → 저장
3. Slack 앱 → Basic Information → **Verification Token**을 `BOT_SETTINGS`의 `SLACK_VERIFICATION_TOKEN`에 넣고, `ENABLE_LUNCH_MATE`에 `true` → `applyBotSettings`

이후 10:30 DM 점심 추천 아래에 버튼이 붙고, PM이 직접 켜고 끕니다. 누르면 그 사람에게만 "켰어요/껐어요" 답이 갑니다. 검증 값이 맞지 않는 요청은 무시하고, 누른 사람 본인 설정만 바뀝니다.

## 피드백

버튼 응답(위 1~3)이 설정돼 있으면 DM 맨 아래에 `👍 도움됐어요 / 👎 아쉬워요 / ✍️ 자세히 남기기`가 붙습니다(14:00의 "새 소식 없음" 한 줄에는 붙지 않음). 👍/👎은 봇 시트 `BOT_FEEDBACK` 탭에 시각·Slack ID·이름·날짜·회차·평가로 쌓이고, ✍️는 구글 폼을 엽니다(응답은 폼에 연결된 시트 탭).

## 쉬는 날

주말, 공휴일("대한민국의 휴일" 캘린더에서 설명이 "공휴일"인 날만, 기념일은 근무일), `COMPANY_HOLIDAYS`의 날짜에는 정기 DM과 Slack 미리 수집을 하지 않습니다. 캘린더를 읽지 못하면 근무일로 보고 보냅니다.

## 날씨

`ENABLE_WEATHER=true`면 17:00 DM 끝에 내일 날씨 한 줄이 붙습니다. Open-Meteo 무료 API(키 없음)를 하루 한 번 조회하고, 실패하면 그 줄만 빠집니다. 이 API는 "비상업적 무료" 조건이므로 회사 사용 가능 여부를 확인하고 씁니다.

## 하지 말 것

- 원본 업무 시트에 쓰기 — 봇은 사본만 읽고, 쓰기는 봇 전용 시트에만 합니다.
- 10:15~11:10, 13:45~14:40, 16:45~17:40(정기 회차 ±15분 + 이어 보내기 20분) 사이에 코드 업로드 — 이어 보내기가 옛 코드와 새 코드로 섞입니다.
- `sendScheduledBriefing11/14/17`을 시험 삼아 실행 — 실제 PM 전원에게 갑니다. 시험은 `sendMy…Test`로 합니다.
