## 연결 앱(PM 개인 캘린더 연결) — 별도 Apps Script 프로젝트

PM이 링크로 여는 웹 화면(`doGet`)과 버튼(연결·지금 갱신·해제), 본인 계정의 5분 자동 갱신(`syncMyMeetings`, 평일 10:00~11:15·16:00~17:15)만 있습니다. 관리자가 직접 실행할 함수는 없습니다.
