## 10/26 수정 과정

1. **요청:** 회차를 10:30 · 14:00 · 17:00으로 바꾸고, 14:00은 새 소식만 보내고, 공휴일은 쉬고, 피드백을 받는다.
2. **구현:** 트리거 3개와 오후 업데이트(29번), 공휴일(28번), 피드백(30번) 파일을 추가했다.
3. **문제 발견:** 새 PM을 연결하다가, 명단에 한 명이라도 문제가 있으면 **회차 전체가 멈추는** 구조를 찾았다. 캘린더 연결 명단도 같았다.
4. **해결:** 문제 있는 PM만 빼거나 업무 없이 보내고, 관리자 요약에 "명단 확인 필요"로 알린다.
5. **전체 리뷰:** 곳곳에 남은 "11시·17시"를 한 번에 통일했다. 그 과정에서 오류 3개도 고쳤다.
   - 14:00 트리거를 확인하지 않던 점검
   - 11시 트리거를 다시 만들던 예전 함수
   - 시트만 보낸 발송을 "기록 없음"으로 보던 로그
6. **검증:** 테스트 36개 → 회차 금지 시간이 지난 뒤 업로드 → 원격 일치 → 상태 로그와 시험 DM으로 확인했다.
7. **알게 된 점:** 회차 시간대 밖(예: 18시)에 시험 DM을 보내면 Slack 자료가 60분을 넘어 "읽어오지 못했습니다"가 나온다. 정상 동작이다. 미리 보려면 `collectBbpmSnapshot`을 먼저 실행한다.
